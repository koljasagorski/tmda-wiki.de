// Das Konzept

Beide Seiten kaufen.

Colonel Tom Parker — Elvis' Manager — hat nicht nur „I Love Elvis"-Buttons verkauft. Er hat auch „I Hate Elvis"-Buttons verkauft. Beide Seiten. Beide kaufen. Das ist Genialität.

„Ich bin kein Fan von" ist das zeitgemäße Gegenstück: ein T-Shirt-Label das sagt was du wirklich denkst. Kein Fan? Shirt. Fan? Auch ein Shirt. Kuratiert. Ehrlich. Ohne Logo-Overload.

„Find mich ruhig scheiße — aber gib einen Zehner rüber, wenn du mich schon scheiße findest."
— Fynn Kliemann, TMDA #63, über das Colonel-Parker-Prinzip

// Was macht es anders

Shirt. Schrift. Fertig.

Das Shirt

  • Schwere 220g Baumwolle, eigener Schnitt
  • Schwarze Schrift auf weißem Stoff
  • Weiße Schrift auf schwarzem Stoff
  • Kein Spreadshirt. Kein Abo. Kein Blödsinn.
  • 34 €. Einmal kaufen. Für immer tragen.

Die Kuratierung

  • Nicht jeder Satz kommt drauf — wir entscheiden
  • Keine Beleidigungen. Kein Hate. Nur Meinungen.
  • Zu jedem „Kein Fan von" gibt es ein „Fan von"
  • Eigene Edition jede Saison, Community-Votes
  • Juristisch unbedenklich: eine Meinung ist erlaubt
