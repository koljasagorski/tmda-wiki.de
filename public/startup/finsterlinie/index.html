Konzeptbeschreibung

Jeder will ein Penthaus-Büro mit Glasfront und Ausblick auf den Berliner Fernsehturm. Finsterlinie demokratisiert diesen Traum: Ein extrem schmales Hochhaus, das fast ausschließlich aus Fensterfassade besteht. Kein Platz für Abstellkammern, Schränke oder schlechte Laune.

Die Dreieckskonstruktion löst das Stabilitätsproblem (Dreieck besteht, Viereck vergeht). In der Tokio-Version stabilisiert ein nahe gelegener Berg die Rückseite. Für die Kontinent-Variante: Die Erdkrümmung gleicht die Neigung automatisch aus, sobald das Gebäude lang genug ist.

Das Baumaterial stammt größtenteils von The Line (Dubai) — das Projekt wurde abgeblasen, das Material liegt auf halber Strecke. Logistisch ideal.

Tokio als Startpunkt

Die Berge rund um Tokio bieten eine natürliche Rückenlehne für das Gebäude. Drohgangfrei. Stabilitätsrating: gut (laut Fynn). Ausblick auf Fuji optional. Keine Waffenverbote zu umgehen.

Phase 2: Das Dreieck erstreckt sich über mehrere Kontinentalplatten. Tokio bis Russland. Architekten auf Ketamin sagen, das sei kein Problem. Die Streckenplanung wird von bestehenden The-Line-Unterlagen adaptiert.
